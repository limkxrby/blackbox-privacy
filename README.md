# Blackbox Privacy Policy

Effective date: November 10, 2026

This policy covers the Blackbox Chrome extension. The published page is at https://limkxrby.github.io/blackbox-privacy/

- Blackbox stores tab URLs, titles, and group names only on the device.
- The device key stays in chrome.storage.local.
- A passphrase backup is ciphertext and is not uploaded.
- There is no account, no analytics, and no server.
- The data is used only for session restore. It is not sold, not used for advertising, and not transmitted off the device.

Contact: open an issue in this repository.
